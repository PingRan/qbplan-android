# 好友监督

> 持续维护文档
> 最近核对：2026-07-29

好友监督是可选的守护约束方式。用户在开启守护时可以选择普通守护或好友监督守护。

## 如何生效

1. 用户邀请好友并建立监督关系；
2. 好友确认后，用户可以开启好友监督守护；
3. 本次守护期间，部分高风险操作需要请求监督码；
4. 监督码由已绑定的好友提供；
5. 验证通过后，轻变计划才执行对应操作。

## 监督码保护的操作

- 关闭守护；
- 移除守护应用；
- 退出登录或注销账户；
- 精准模式下进入部分系统设置或权限设置。

## 解除监督

解除好友监督需要经过冷静期。冷静期内，好友监督继续生效。

## 能力边界

好友监督用于增加临时绕过守护的成本，不是系统级设备管理或安全防护能力。它不能绝对阻止：

- 卸载轻变计划；
- 强制停止应用；
- 清除应用数据；
- 关闭系统权限。
