# 轻变计划如何工作

轻变计划是一款 Android 手机使用行为辅助 APP。它关注的是用户每一次打开目标应用的动作，而不只是一天结束时的累计使用时间。

## 基本流程

### 1. 选择需要守护的应用

守护范围由用户主动设置。例如，用户可以选择自己希望减少无意识打开的短视频或社交应用。

### 2. 开启守护

根据用户选择的守护模式，轻变计划使用 Android 提供的相关系统能力识别当前打开的应用，并在命中守护规则时显示暂停界面。

### 3. 打开目标应用时先暂停

暂停发生在打开动作当下，让用户有机会意识到自己正在做什么，并重新判断这一次是否真的需要继续。

### 4. 继续或取消

如果确实需要处理消息、工作或其他内容，用户可以继续；如果发现自己只是习惯性点击，可以取消。

轻变计划不以永久禁止使用目标应用为主要方式。Android 用户仍然可以关闭权限、强行停止、清除数据或卸载应用。

## 与系统应用限额的区别

Android 系统应用限额通常在每日累计使用达到设定时间后介入，适合有明确时长目标的人。

打开前暂停在每一次打开目标应用时介入，更关注下意识、重复打开。两种方式可以组合使用。

## 效果边界

轻变计划提供行为提醒和重新选择的机会，但：

- 不能保证用户每次都会取消；
- 不能保证所有用户减少相同的使用时间；
- 不替代用户自己的规则、习惯调整或系统工具；
- 不是医疗、心理或成瘾治疗产品。

## 产品身份

轻变计划不是虚拟机、改机、应用多开、账号隔离、设备信息伪装或脚本挂机工具。
