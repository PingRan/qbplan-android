# 轻变计划如何工作

轻变计划是一款 Android 应用使用守护工具。它在用户选择的应用进入前台时触发干预，并通过使用目的选择、限时放行和放行到期后的再次守护，为本次使用设置边界。

## 基本流程

### 1. 选择需要守护的应用

守护范围由用户主动设置。例如，用户可以选择自己希望减少无意识打开的短视频或社交应用。

### 2. 开启守护

用户可以开启普通守护或好友监督守护。根据所选检测模式，轻变计划使用应用使用情况访问或无障碍服务识别当前前台应用。

### 3. 目标应用进入前台时触发干预

命中守护列表后，轻变计划会中断直接使用并显示干预界面。当前版本支持深呼吸、舒尔特方格、简单舒尔特方格和今日计划。

### 4. 取消，或者选择目的和时长后继续

用户可以取消使用。如果仍需继续，需要完成当前干预、选择本次使用目的，并选择 1、3、5 或 10 分钟的允许时长。

### 5. 放行到期后再次触发守护

轻变计划临时放行目标应用。本次允许时长结束后，如果用户仍在目标应用，会再次触发守护。

轻变计划按用户选择的整个应用进行守护，不识别应用内部的某个具体视频、信息流、聊天或页面。

## 与系统应用限额的区别

Android 系统应用限额通常在每日累计使用达到设定时间后介入，适合有明确时长目标的人。

应用使用守护在选定应用进入时介入，并可为本次使用设置目的和允许时长。两种方式可以组合使用。

## 效果边界

轻变计划提供进入时干预、使用目的选择、限时放行和再次守护等自我管理能力，但：

- 不能保证用户每次都会取消；
- 不能保证所有用户减少相同的使用时间；
- 不替代用户自己的规则、习惯调整或系统工具；
- 不是医疗、心理或成瘾治疗产品。

轻变计划不是系统级锁机或设备管理工具。Android 用户仍然可以关闭权限、强行停止、清除数据或卸载应用。

## 产品身份

轻变计划不是虚拟机、改机、应用多开、账号隔离、设备信息伪装或脚本挂机工具。
