# 守护干预方式

> 持续维护文档
> 最近核对：2026-07-29

当用户选择的应用进入前台并命中守护规则时，轻变计划会中断直接使用并显示守护干预界面。当前版本支持以下方式。

## 深呼吸

显示深呼吸过程和守护提示。完成当前干预后，用户可以取消；如果继续，需要选择本次使用目的和允许时长。

## 舒尔特方格

通过完成舒尔特方格交互增加继续使用前的操作步骤。当前版本同时提供标准和简单两种方格方式。

## 今日计划

在守护界面中展示用户的今日计划。用户可以查看或完成计划，再决定是否继续进入目标应用。

## 继续使用

不同干预方式最终进入相同的继续流程：

1. 完成当前干预；
2. 达到已配置的继续点击次数和点击间隔；
3. 选择本次使用目的；
4. 选择 1、3、5 或 10 分钟允许时长；
5. 临时放行目标应用；
6. 放行时间结束后，如果用户仍在目标应用，再次触发守护。

## 边界

- 每日使用上限用于显示使用边界和提醒，不应描述成系统级绝对锁定；
- 允许使用时段可以限制目标应用的可用时间范围；
- 轻变计划按用户选择的整个应用守护，不识别应用内部的具体视频或页面；
- 不同手机厂商可能影响后台检测和悬浮界面的稳定性。
