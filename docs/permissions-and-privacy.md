# 轻变计划权限与隐私说明

> 持续维护文档
> 最近核对：2026-07-29

轻变计划是一款Android应用使用守护工具。为了识别用户选择的目标应用、显示干预界面并提供计划、提醒、账号和数据同步等功能，应用会根据用户实际使用的功能请求相应系统权限。

用户可以在Android系统设置中撤回权限。撤回后，对应功能可能停止工作，但不代表必须开启所有权限才能使用应用中的每一项功能。

## 守护功能相关权限

| 权限或系统能力 | 主要用途 | 关闭后的影响 |
|---|---|---|
| 应用使用情况访问 | 识别当前正在使用的应用，并支持应用使用情况统计 | 普通模式无法正常完成相应识别和统计 |
| 悬浮窗权限 | 在目标应用上方显示守护干预界面 | 无法正常显示核心干预界面 |
| 辅助服务 | 精准模式下识别当前正在使用的应用 | 精准模式无法正常工作 |
| 通知权限 | 显示轻变计划的运行状态和相关通知 | 状态通知无法正常显示，后台运行稳定性可能受到影响 |
| 自启动、电池优化和后台运行设置 | 降低守护服务被系统后台策略清理的概率 | 锁屏、长时间后台或系统清理后可能停止守护 |

不同Android版本和手机厂商对自启动、电池优化、后台弹出和后台运行的设置方式不同。相关设置只能提高稳定性，不能保证应用永远不会被系统清理。

## 其他功能可能使用的权限

| 权限或系统能力 | 主要用途 | 关闭后的影响 |
|---|---|---|
| 日历权限 | 创建和读取用户选择的提醒日程 | 无法使用相应日程提醒能力 |
| 相册或图片访问 | 选择头像、背景或相关图片 | 无法选择对应图片 |
| 存储写入 | 保存用户主动导出的文件或缓存图片 | 无法完成相应保存操作 |
| 网络访问 | 账号登录、会员验证、必要的数据同步和网络功能 | 无法使用相应网络功能 |

## 辅助服务读取什么？

轻变计划的精准模式使用辅助服务判断当前正在使用的应用是否属于用户设置的守护范围。

当前辅助服务配置不允许读取目标应用窗口正文，不用于读取：

- 聊天内容；
- 短视频或信息流内容；
- 用户输入的文字；
- 密码。

辅助服务属于敏感系统能力。用户应根据自己的需要决定是否开启，并可以随时在系统设置中撤回。

## 轻变计划是否完全离线？

不是。轻变计划包含账号登录、会员验证和数据同步等网络功能，因此不应描述成“没有网络权限”“完全离线”或“所有数据绝不上传”。

部分守护设置和使用记录默认保存在本地设备中；在用户登录、启用相关功能或满足相应同步条件时，部分必要数据可能由服务器处理。具体收集范围、使用目的、处理条件和用户权利以当前公开的隐私政策为准。

## 是否读取应用列表？

为了让用户选择需要守护的应用，轻变计划需要读取设备中可启动应用的基本信息，例如应用名称、包名和图标。

轻变计划按用户选择的整个应用进行守护，不识别该应用内部的具体视频、信息流、聊天或页面。

## 用户可以撤回权限吗？

可以。用户可以通过Android系统设置撤回相关权限，但对应功能会停止工作或变得不稳定。

用户还可以根据隐私政策中提供的方式，行使查询、更正、删除或撤回授权等权利。
