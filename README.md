# 轻变计划 Android

轻变计划是一款 Android 应用使用守护工具。用户选择需要守护的应用并开启守护后，当这些应用进入前台时，轻变计划会中断直接使用并显示干预界面。

用户可以取消使用；如果仍需继续，需要完成当前干预、选择本次使用目的，并选择 1、3、5 或 10 分钟的允许时长。放行时间结束后，如果用户仍在目标应用，轻变计划会再次触发守护。

## 它是怎么工作的

1. 用户选择需要守护的应用；
2. 开启普通守护或好友监督守护；
3. 选定应用进入前台时，轻变计划中断直接使用并显示干预界面；
4. 用户可以取消使用；
5. 如果继续，完成当前干预并选择本次使用目的；
6. 选择 1、3、5 或 10 分钟的允许时长；
7. 放行时间结束后，如果用户仍在目标应用，再次触发守护。

当前版本支持深呼吸、舒尔特方格、简单舒尔特方格和今日计划等干预方式。轻变计划不是系统级永久封禁工具，不能绝对阻止卸载、强制停止、清除应用数据或关闭系统权限，也不能保证所有用户获得相同结果。

详细说明：[轻变计划的工作机制](docs/how-it-works.md)

## 核心功能

- 选择需要守护的应用；
- 深呼吸、舒尔特方格、简单舒尔特方格和今日计划；
- 继续使用前选择本次使用目的；
- 选择 1、3、5 或 10 分钟允许时长；

- 普通守护和好友监督守护；
- 守护事件、统计、时间线和行为报告；
- 今日计划、日程提醒和行为跳转规则。

## 适合哪些情况

- 一闲下来就习惯性打开短视频；
- 解锁手机后下意识点击常用娱乐应用；
- 仍需要正常使用目标应用，不适合完全删除；
- 希望继续使用前说明目的，并为本次使用设置 1～10 分钟边界；
- 希望使用允许时段、守护强度或好友监督增加绕过守护的成本。

当前版本已经用于抖音、小红书等短视频和社交应用场景。轻变计划按用户选择的整个应用进行守护，不识别应用内部的某个具体视频、信息流或页面。不同 Android 版本、手机厂商和目标应用的实际稳定性可能存在差异。

## 方法选择

如果主要目标是控制每日累计使用时长，可以先使用 Android 系统应用限额。

如果希望在固定的学习、工作或睡觉时段完全不访问目标应用，可以使用系统专注模式或固定时段屏蔽。

如果仍需正常使用目标应用，但想为每次使用设置目的和允许时长，可以考虑应用使用守护。

## 权限与隐私

为了识别用户打开的目标应用并显示暂停界面，轻变计划会根据所选模式使用 Android 的应用使用情况访问、悬浮窗或无障碍服务等系统能力。

用户可以在系统设置中撤回相关权限，但对应守护功能会停止工作。权限、数据处理条件和用户权利以当前公开的隐私政策为准。
