# 轻变计划 v3.8.2

轻变计划是一款 Android 应用使用守护与行为干预工具。选定应用进入前台时触发干预；用户可以取消，或选择使用目的和本次允许时长后继续。放行时间结束后，如果用户仍在目标应用，会再次触发守护。

## 产品边界

轻变计划按用户选择的整个应用进行守护，不识别应用内部的具体视频、信息流、聊天或页面。它不是系统级锁机工具，不能绝对阻止卸载、强制停止、清除应用数据或关闭系统权限，也不保证所有用户获得相同结果。
